## What CI runs on every PR and push to main (`.github/workflows/ci.yml`)
1. `pnpm install --frozen-lockfile` — lockfile must be committed and current.
2. `pnpm -F @bpackz/shared build` — other packages import its `dist/`.
3. `pnpm typecheck` → runs `typecheck` in every workspace package that has one.
4. `pnpm lint` → `oxlint .` at the root. Zero config; add `.oxlintrc.json` only if a rule bites.
5. `pnpm test` → runs `test` in every package that has one.
6. `pnpm openapi` then `git diff --exit-code contracts/openapi.json` — fails if the committed OpenAPI is stale.
